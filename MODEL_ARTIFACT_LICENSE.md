# Adapter artifact license

The Control-v2 and Selective-correction-v2 LoRA adapter files produced by this
repository are released under the Apache License 2.0, matching the license of
the frozen `Qwen/Qwen3-4B-Instruct-2507` base model. The full license text is
included in `APACHE-2.0.txt`.

Base-model weights are not redistributed. Users must obtain the base model
from its upstream source and comply with its license and terms. The adapter
archive should include this notice, the adapter configuration files, and the
recorded checksums.
